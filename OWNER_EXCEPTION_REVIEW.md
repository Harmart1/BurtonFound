# Owner exception review

Read-only exception queue reuses the existing owner-only date-range bookkeeping and optional Stripe comparison. Flags local refunded/review orders, fulfillment needs_attention, inconsistent amounts, reported refunds and provider issues. Filters and PII-free CSV support manual review. It does not store a separate return case, contact customers, issue refunds, mark refunds settled, restock goods or approve shipments. No refund amounts are inferred from local order totals. Stripe comparison remains bounded to 25 matching orders. Owner workspace leaves private dashboard when identity changes or recovery begins; this is an extra client-side privacy safeguard and not a replacement for server authorization. Use manual return documentation and individual Stripe refund/balance records for any actual customer return.
