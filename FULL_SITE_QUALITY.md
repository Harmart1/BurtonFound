# Full-site quality gate

Run `npm run build:marketing && npm run audit:site`. Checks all catalogue primary, gallery and set-member photos, basic image file signatures, SKU uniqueness, price, physical catalogue identifiers, generated product links and local HTML/CSS paths. Reports by collection and separates review notes from blocking failures. Runs on relevant changes, weekly and before deployment. Reports are downloadable from GitHub Actions. No external links, real stock, physical condition, customer data, real rates or payment activation are verified by the audit. The automobile catalogue remains enquiry-only; its missing SEO pages are reported separately and not treated as sellable inventory. The gift comparison keyboard focus is preserved after an in-place rerender.
