# Private owner operations tools

Open /admin/orders.html as an authorized owner. The Business reports panel provides an on-demand, read-only UTC date-range order export (up to 367 days, maximum 5,000 records; choose a smaller range if needed). It defaults to live Checkout records and separates test and unknown session prefixes. The totals cover valid records with payment_status=paid only, not net receipts, deposits, fees, actual refunds, tax liability or a journal entry. The residual between total and item/shipping amounts is unclassified, never assumed to be sales tax. Reconcile the CSV against Stripe balance transactions, payouts and receipts before importing into accounting software. Dates are order creation dates in UTC, not bank settlement dates. Export while no orders are being changed for the most consistent period snapshot. No customer name, email or delivery address is included in this export, but order/payment identifiers remain confidential.

The inventory button compares the current 229-listing catalogue with the live public database view, highlights missing SKUs, price mismatches, unavailable items, database-only SKUs and unverified/disabled listings marked available. The download is a review worksheet, not an inventory import. No saleable stock or dimensions are inferred. The recent-orders view defaults to attention-first and automatically loads pending holds after authorized sign-in. It still displays only the latest 100 order records; historical bookkeeping is a separate report. Email and labels remain manual until provider configuration is approved.

All new API reads require owner authorization. No new service, database migration, payment activation, or carrier charges.

The recent order dashboard labels live, sandbox and unknown records. It withholds carrier links, real packing-slip printing, delivery address copying and customer-email drafting for non-live/unknown records; fulfillment status changes remain available for controlled sandbox testing. The existing filtered order-register export now includes the record mode. Daily monitoring of the new private endpoint is enabled only after deployment, avoiding a premature 404 check.
