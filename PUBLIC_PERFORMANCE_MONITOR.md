# Daily public performance snapshot

Six anonymous GET probes: home, automobile collection, account, public health/catalogue and a featured product WebP. Strict same-origin HTTPS redirects, bounded transfers and content verification. Each run retains a 30-day JSON/Markdown artifact with response size, TTFB and elapsed time. Provisional body-size budgets and a 5-second synthetic elapsed threshold are review warnings, not performance guarantees; content failure fails the run. Runs daily or manually and never contacts private endpoints, tracks visitors, creates orders or changes DNS. This is not real-user Core Web Vitals, a browser benchmark, or load testing. The health assertion intentionally expects preview-only checkout; update the approved launch test when transitioning to live checkout.
